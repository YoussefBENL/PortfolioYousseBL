Séries Temporelles CO2 — Station Châtelet (R)
SAÉ Séries Temporelles — Analyse, Décomposition & Prévisions

Analyse des concentrations de CO2 (ppm) mesurées à la station de métro Châtelet entre 2018 et 2025. Objectif : comprendre l'évolution de la qualité de l'air, identifier l'impact du confinement Covid-19 (chute brutale en 2020), et comparer trois méthodes de prévision jusqu'à fin 2025.

Pipeline d'analyse — Code R

Fusion de deux fichiers CSV (2013–2020 et 2020–2025), nettoyage des valeurs tronquées (symbole <), agrégation en moyennes journalières et calcul de moyennes mobiles MM7, MM30 et MM365.

library(tidyverse); library(lubridate); library(zoo); library(forecast) data1 <- read_csv2("chatelet_2013_2020.csv") %>% select("DATE/HEURE", CO2) %>% mutate(CO2 = as.numeric(str_replace(CO2, "<", ""))) data2 <- read_csv2("chatelet_2020_2025.csv") %>% select("DATE/HEURE", CO2) %>% mutate(CO2 = as.numeric(str_replace(CO2, "<", ""))) CO2_jour <- bind_rows(data1, data2) %>% rename(DateHeure = "DATE/HEURE") %>% mutate(DateHeure = ymd_hms(DateHeure), Date = as_date(DateHeure)) %>% filter(DateHeure >= "2018-11-22") %>% group_by(Date) %>% summarise(CO2_moy = mean(CO2, na.rm = TRUE)) %>% mutate(mm7 = rollmean(CO2_moy, 7, fill=NA, align="right"), mm30 = rollmean(CO2_moy, 30, fill=NA, align="right"), mm365 = rollmean(CO2_moy, 365, fill=NA, align="right"))

Transformation en objet ts (fréquence 365 j/an) puis décomposition additive en tendance, saisonnalité et résidus.

CO2_ts <- ts(CO2_jour$CO2_moy, start = c(year(min(CO2_jour$Date)), yday(min(CO2_jour$Date))), frequency = 365) # Décomposition additive decomp <- decompose(CO2_ts, type = "additive") plot(decomp) # Série désaisonnalisée + boxplot des résidus CO2_deseason <- CO2_ts - decomp$seasonal boxplot(decomp$random, main="Résidus", col="lightblue", horizontal=TRUE)
Observation : Chute brutale du CO2 en 2020 (confinement Covid) puis remontée progressive. Saisonnalité ±40 ppm liée aux variations de fréquentation week-end / semaine.

Trois modèles comparés : SARMA (auto.arima), Holt-Winters additif, et Régression Polynomiale degré 2 sur série désaisonnalisée.

h_days <- as.numeric(as.Date("2025-12-31") - max(CO2_jour$Date)) # SARMA — sélection automatique via AIC pred_sarma <- forecast(auto.arima(CO2_ts), h = h_days) # Holt-Winters additif pred_hw <- predict(HoltWinters(CO2_ts, seasonal = "additive"), n.ahead = h_days) # Polynomiale degré 2 + réinjection saisonnalité t <- 1:length(CO2_deseason) reg_poly <- lm(CO2_deseason ~ t + I(t^2)) t_fut <- (max(t)+1):(max(t)+h_days) pred_poly <- predict(reg_poly, newdata=data.frame(t=t_fut)) + rep(decomp$seasonal[1:365], length.out=h_days)

Évaluation des trois modèles sur la période de test (sept. 2024 → janv. 2025).

ModèleForcesLimites
SARMARMSE le plus bas sur période test, prévisions stablesPeu réactif aux pics extrêmes
Holt-WintersCapture bien la saisonnalité court termeDiverge sur horizon >6 mois
PolynomialeTendance globale lisibleSurestime la hausse sur longue période
Conclusion : SARMA est le modèle le plus fiable (~560 ppm en 2025). Holt-Winters est plus volatile mais précis à court terme. La régression polynomiale surestime la hausse tendancielle.

Tests Statistiques — Cardio Good Fitness
Rapport d'étude — Analyse des profils clients, IUT Paris Rives de Seine

Étude statistique portant sur 180 clients de l'entreprise Cardio Good Fitness, ayant acheté l'un des trois modèles de tapis de course : TM195, TM498 ou TM798. Objectif : identifier les différences de profils selon le genre et le modèle acheté.

Analyse statistique — Code R

Préparation du jeu de données : factorisation des variables, recodage du niveau d'éducation en tranches et catégorisation de l'usage.

library(tidyverse); library(GGally); library(corrplot) don <- read.csv("CardioGoodFitness.csv", header=TRUE, sep=",") don <- don %>% mutate( Product = factor(Product), Gender = factor(Gender), MaritalStatus = factor(MaritalStatus), Fitness = factor(Fitness), Niv = cut(Education, breaks=c(11,14,16,21), labels=c("12-14", "14-16", ">16")), Usage_cat = case_when( Usage <= 3 ~ "Faible", Usage > 3 & Usage <= 5 ~ "Modere", Usage > 5 ~ "Eleve" ) %>% factor(levels=c("Faible", "Modere", "Eleve")) )
Échantillon : 180 clients — 57,8 % hommes, âge moyen 28,8 ans, revenu moyen 53 720 $. Produit le plus vendu : TM195 (44,4 %), suivi de TM498 (33,3 %) et TM798 (22,2 %).

Test du Chi² pour tester l'indépendance entre le genre et le modèle de tapis acheté. Effectifs théoriques tous > 5.

# Test Chi² d'indépendance Genre × Produit chisq.test(table(don$Gender, don$Product), correct=FALSE) # X-squared = 12.9, df = 2, p-value = 0.0016 ** # Visualisation : barplot empilé normalisé ggplot(don) + aes(x=Gender, fill=Product) + geom_bar(position="fill") + labs(title="Répartition des produits selon le genre", x="Genre", y="fréquence", fill="Produit acheté") + theme_minimal()
Résultat Chi² : p-value = 0,0016 < 0,05 → dépendance significative entre genre et produit. Le TM798 est très majoritairement acheté par des hommes (27,5 % contre 9,8 % chez les femmes).

Tests de Student pour comparer les moyennes (revenu, miles) entre hommes et femmes. Corrélation de Spearman entre âge et revenu.

# Comparaison du revenu selon le genre t.test(Income ~ Gender, data=don) # t = -2.93, p-value = 0.004 ** → Hommes : 56 563 $ vs Femmes : 49 829 $ # Comparaison des miles prévus selon le genre t.test(Miles ~ Gender, data=don) # t = -3.12, p-value = 0.002 ** → Hommes prévoient davantage de km # Corrélation de Spearman : âge vs revenu cor.test(don$Age, don$Income, method="spearman") # rho = 0.47, p-value < 0.001 *** → corrélation positive modérée # Boxplot revenu / genre ggplot(don, aes(Gender, Income, fill=Gender)) + geom_boxplot() + geom_hline(yintercept=mean(don[don$Gender=="Female",]$Income), col="red") + geom_hline(yintercept=mean(don[don$Gender=="Male",]$Income), col="blue") + theme_minimal()

Méthodes Factorielles — ACP, AFC, ACM, MDS
SAÉ 4.02 — Reporting d'une analyse multivariée, IUT Paris Rives de Seine

Rapport complet d'analyse multivariée appliquant les quatre grandes méthodes de réduction de dimension : ACP (données quantitatives), AFC (tableaux de contingence), ACM (données catégorielles) et MDS (données de distances).

Méthodes & Jeux de données

ACP sur body_full.csv (mesures corporelles) et athle_records.csv (records athlétisme par pays). Comparaison prcomp() vs FactoMineR::PCA() — impact de la normalisation.

library(FactoMineR); library(factoextra) # ACP sur données corporelles (variable qualitative genre en supplémentaire) body <- read.table("body_full.csv", header=TRUE, sep=";", dec=",") pca <- PCA(body, scale.unit=TRUE, graph=TRUE, quali.sup=25) # Individus colorés par genre + ellipses de confiance fviz_pca_ind(pca, geom.ind="point", col.ind=body$gender, addEllipses=TRUE, legend.title="Groupe") # Cercle des corrélations pour interpréter les axes fviz_pca_var(pca) # Sur records athlétisme — sans normalisation vs avec scale() athlete <- read.csv("athle_records.csv", sep="\t", header=TRUE, dec=",") fviz_eig(prcomp(scale(athlete[,-1])), addlabels=TRUE)
Constat : Sans normalisation, les variables à grande amplitude (poids, taille) dominent entièrement la première composante. FactoMineR::PCA() normalise automatiquement contrairement à prcomp().

AFC sur le tableau de contingence Pays × Discipline des Prix Nobel (data_CA_NobelPrize_withMaths.csv).

library(FactoMineR); library(factoextra) # Chargement et préparation du tableau de contingence Nobel nobel <- read.csv("data_CA_NobelPrize_withMaths.csv", header=TRUE, sep=";", row.names=1) # AFC — analyse de correspondances res_ca <- CA(nobel, graph=FALSE) # Visualisation : biplot lignes (pays) et colonnes (disciplines) fviz_ca_biplot(res_ca, repel=TRUE, col.row="steelblue", col.col="tomato") # Part de variance expliquée par chaque axe factoriel fviz_eig(res_ca, addlabels=TRUE)
Lecture : Les pays proches d'une discipline dans le biplot y sont sur-représentés. Les États-Unis dominent l'axe 1 (toutes disciplines), tandis que la France est davantage associée à la Littérature.

ACM sur chiens.rda — caractéristiques qualitatives de races canines (taille, poids, vitesse, intelligence…).

library(FactoMineR); library(factoextra) # Chargement des données sur les races de chiens load("chiens.rda") # ACM — Analyse des Correspondances Multiples res_mca <- MCA(chiens, graph=FALSE) # Eboulis des valeurs propres fviz_eig(res_mca, addlabels=TRUE) # Nuage des individus (races) et des modalités fviz_mca_ind(res_mca, repel=TRUE) fviz_mca_var(res_mca, repel=TRUE, ggtheme=theme_minimal())
Résultat : L'ACM révèle que la première dimension oppose les races de grande taille / forte utilité aux petites races d'agrément. La seconde dimension est liée à la vélocité et l'intelligence.

MDS sur une matrice de distances inter-villes françaises et sur birthwt.csv (données médicales) pour reconstituer une carte à partir des distances.

# Matrice de distances inter-villes villes <- read.csv("Distances_Inter_Villes_Matrice.csv", header=TRUE, sep=";", row.names=1) dist_mat <- as.dist(villes) # MDS classique (métrique) mds_res <- cmdscale(dist_mat, k=2, eig=TRUE) coords <- as.data.frame(mds_res$points) # Reconstitution de la carte des villes ggplot(coords, aes(x=V1, y=V2, label=rownames(coords))) + geom_point(color="steelblue", size=3) + geom_text(vjust=-0.8, size=3) + labs(title="Carte reconstituée par MDS") + theme_minimal()
Résultat : La carte reconstituée par MDS à partir des seules distances routières correspond fidèlement à la géographie réelle des villes françaises, validant la qualité de la représentation (stress faible).
